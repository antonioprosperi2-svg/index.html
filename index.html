🐝 BeeEngine JS
Documentazione npm GitHub

Motore di gioco 2D in JavaScript

BeeEngine JS è un motore leggero per giochi HTML5 su Canvas: camera, layer di disegno, particelle, collisioni e culling, senza dipendenze.

Leggi la documentazione Codice su GitHub 
npm install beeengine

Cosa trovi nel motore

🎥

Camera 2D

Follow del giocatore, scroll, limiti del mondo e conversione screenToWorld / worldToScreen.

🗂️

Layer di disegno

Ordine di rendering per layer, y-sort per i giochi top-down e UI sempre sopra la scena.

✨

Particelle

Burst di particelle con pool di oggetti senza allocazioni e culling sull'area visibile.

💥

Collisioni e culling

Disegna e controlla solo ciò che serve, per restare fluido anche su mobile.
